# Objectives of the cue revision

This pass keeps the first pilot's question about explicit contrast and changes the cue, not the sample. The first-pilot objectives remain in [../objectives.md](../objectives.md).

## The question

When two tools are easy to confuse, can the contrast be stated as one source-supported difference, cheaply enough to test, without treating fewer words as success?

Success is not a shorter cue. A shorter cue can drop the difference, imply an exclusion the sources do not support, or remove a hint that would have guided an argument. A longer cue can still be the right contrast. Whether either version improves tool selection enough to justify its cost is a question for a separately authorized U/S/X/SX benchmark run. This pass does not start that run.

## What is compared

The control is still the frozen first-pilot U. S stays the sealed first-pilot compression. The new conditions are:

| Condition | What is rendered |
| --- | --- |
| U | The frozen first-pilot catalogue. Unchanged. |
| S | The frozen first-pilot compression. Unchanged. |
| X | Frozen U, plus the new cue where a rival still qualifies. |
| SX | Frozen S, plus that same new cue, at the same path, with the same one-space separator. |

The first-pilot X and SX stay in [../rendered/](../rendered/) as the record of the first cues. They are not overwritten.

## What this pass is

- A second, versioned edit of the contrast strings on the same 12 catalogues.
- A check that each kept cue names one rival and one documented difference, and that the polynomial-versus-quadratic class contrast is not reused.
- Local token deltas against the frozen U, S, X, and SX totals. The counts are local `o200k_base` counts, not provider usage and not official scores.

## What this pass is not

- It does not rescore the closed v1.1 result, and it does not move the 10% target.
- It does not call a provider or run the 12 cases, or the 840 cases, as a benchmark.
- It does not change S, the selection, the conversion, the renderer, or the original BFCL files.
- It does not infer a population rate from 8 `multiple` catalogues, or from the 2 + 2 controls.
- It does not treat 6 of 8 cued catalogues as evidence that contrast helps. That count is an opportunity to test contrast.
